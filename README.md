# Student Marks Analysis – Excel

## 📌 Project Overview

This is a Level 1 Data Analyst project created using Microsoft Excel.

The project analyzes the academic performance of 100 students across five subjects:
- Maths
- Physics
- Chemistry
- English
- Computer

## 🛠️ Tools Used

- Microsoft Excel
- Excel Formulas
- Sorting & Filtering
- INDEX + MATCH
- Charts
- Dashboard

## 📊 Analysis Performed

- Total number of students
- Average total marks
- Highest and lowest marks
- Pass/Fail analysis
- Subject-wise average marks
- Top 5 students
- Bottom 5 students
- Percentage analysis

## 📈 Visualizations

- Subject-wise average marks
- Pass vs Fail
- Top 5 students
- Bottom 5 students

## 💡 Key Insights

- 100 students were analyzed.
- 86 students passed.
- 14 students failed.
- English had the highest subject average.
- Maths had the lowest subject average.
- Abhishek Rana was the top-performing student with 436 marks.

## 🎯 Learning Objective

This project was created to build a strong foundation in Excel-based data analysis and prepare for more advanced Data Analyst projects.
